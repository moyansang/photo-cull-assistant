AI选片助手 Lightroom Classic 插件

安装一次：
1. 保留 PhotoCullAssistant.lrplugin 整个文件夹，不要只复制里面的文件。
2. Lightroom Classic → 文件 → 增效工具管理器 → 添加，选择 PhotoCullAssistant.lrplugin 文件夹并启用。
3. 使用 文件 → 增效工具附加功能 → 导入 AI选片助手结果。
   （部分中文版本菜单译名略有差别；本插件位于 Library / 图库模块菜单。）

每次使用：
1. EXE 扫描后进入“AI 选片与 LR 导出”，完成 API 或网页选片。
2. 点击“导出到 LR”生成工作区 lightroom_results.json；不复制或移动任何照片。
3. 在 LR 插件选择本次 lightroom_results.json，检查匹配数量后应用。
4. LR 会显示星级/弃置；不必执行“从文件读取元数据”。

说明：
- 仅适用于 Lightroom Classic，不支持云端版 Lightroom。
- 原照片必须已导入当前 LR 目录，按完整路径匹配。文件移动后请重新扫描和导出。不按同名猜测、不改虚拟副本。
- RAW+JPEG 分别匹配；如果 LR 没有单独导入 JPEG，该项会显示未匹配，不影响 RAW。
- 结果没有指定的字段保留 LR 原值；普通低星级不自动等同弃置。
- 星级和旗标独立。只填星级保留原旗标，需要清除弃置时在 LR 中修改。
- EXE 和插件均不生成、移动或删除 XMP，不触碰旧 XMP 或调色数据。
- Lightroom 自己仍可能写 XMP：如需照片目录不出现 XMP，关闭 目录设置 → 元数据 → 自动将更改写入 XMP，且不要手动保存元数据到文件。
- 每次导入在 LR 目录内保存上次匹配及变更前状态报告；重复导入同一结果不会叠加星级。
- 扫描不会替换上次导出；重新“导出到 LR”才会替换 JSON。需要留存旧导出请先备份。

开发验证：Python 导出测试和 Lua 插件模拟目录测试；实际 LR 菜单与目录写入需在已安装 Lightroom Classic 的环境验证。

SDK：Adobe Lightroom Classic SDK（API 文档镜像 https://lrc.mcor.dev/）。
json.lua：rxi/json.lua，MIT 许可（许可在文件头）；固定提交 dbf4b2dd2eb7c23be2773c89eb059dadd6436f94。

清晰度待确认：
- 更新本插件后在 LR 增效工具管理器重载。
- EXE 导出会附带 focus_review 状态；即使没有星级，也可以单独同步待确认标记。
- 首次导入有待确认照片时，插件自动添加关键词 AI选片_清晰度待确认，并创建同名智能收藏夹。图库“关键字”面板与左侧“收藏夹”均可查看。
- 复核原图后可手动移除该关键词，照片即离开智能收藏夹。仅修改星级或弃置不会自动清除待确认关键词。
- 再次导入明确已清楚或已技术弃置的分析结果，会移除本插件专用关键词；旧格式文件不修改该关键词。重复导入旧的待确认结果会重新加上标记。
- 不改其他关键词；新建的专用关键词默认不随成片导出。仍遵循 LR 自身的自动写 XMP 设置。
- 当前依据本地技术检查结果生成待确认状态，AI 二次判断功能尚未加入。
