## 合理复现的范围

普通克隆包含当前四份 ONNX 基础推理模型。安装 [开发依赖](development.md) 后运行完整测试和 `python launcher.py --self-test <报告路径>`；可先执行 `python body_models/download.py --verify-only` 验证两份身体模型。源码与 EXE 自检都会实际加载并执行身体模型。

Python/Tcl/Tk、Git、系统字体和打包工具属于本机环境，不从另一台机器复制进仓库。字体使用系统候选并提供后备；LR 插件源码已包含，Lightroom Classic 应用本身不包含。`tools/evaluate_person_orl.py` 要求显式提供数据和输出目录，没有自动下载；其外部评估数据不是运行应用或合成回归测试的前提。

依赖声明仍有版本范围，尚未提供按平台锁定全部传递依赖的 lockfile，因此本次目标是可运行、可测试的源码和固定基础模型，不承诺跨时间逐字节重建同一 EXE。严格可复现构建需要另定目标 Python/Windows 版本和依赖锁定策略。整体软件尚无统一许可证，第三方模型许可不能替代整体软件授权。

未发现额外必需的大模型缺失，不为假设的需求下载资源。未来微调所需训练定义、可导入 checkpoint、许可数据和导出验证尚需单独确定，见[微调边界](body-model-baselines.md)。

## 提交前边界

忽略规则不保护任意位置的私人文件，也不阻止 `git add -f`。照片和工作区放在仓库外；提交前审查暂存清单。当前无现有跟踪文件需要移出索引，不删除本地文件、不改写 Git 历史。新增权重会增加仓库体积，后续实验权重不应反复提交为基础模型。
