# 补框进度与参考积累

在“检测/调整人脸框”选定参考人物，打开“补齐人脸”。Y 确认的框（含修正后确认）自动积累，下次打开或点击“重新查找未确认”时使用。X 记录错误候选用于排序降权；P 只保存跳过进度，不作为匹配依据。自动候选不会自行成为参考。

确认、拒绝、跳过、手动调整及停留照片保存在工作区 assist-feedback.json。关闭重开恢复审核状态；尚未审核的候选可重新计算。确认状态与采用到人脸草稿分开，仍需“采用选中候选”和“重新扫描修改过的图片”。

不需要命名人物。只把对当前参考明确确认的照片关联到同一参考链；从链内已确认照片发起补框可复用积累。独立人物不会仅凭相似外观自动合并。

原照片使用相对照片根目录的路径与大小、修改时间核对，避免换盘符后丢失关联；源文件改变时不套用旧审核或参考。每个人物链最多保留 32 个正向样本，每轮使用主参考及最多 5 个积累参考，优先同组和较近确认记录。最多 5 个负参考，检测仍对每个目标运行一次。

原窗口内“移除此参考”只删除选中的积累样本，“清空积累”停用该链的正负参考；不删除原照片、已保存人脸框及审核进度。本轮已开始的匹配使用启动时快照，调整参考后请开始新一轮。

工作区整体迁移包含该文件；清空工作区也会清除该记录。记录损坏时保留原文件并提示，不覆盖。无 API 调用、无模型训练。多参考效果仍需使用实际侧脸、遮挡等照片验证，不保证找对人物。

本地构建 3 增加不确定审核：证据不足或候选相近时不预选框，可从待核对候选选择或手动画框后再按 Y。恢复的未确认旧候选重新计算。详见 [人物候选审核与离线评测](person-review-evaluation.md)；外观分数不是身份概率。
