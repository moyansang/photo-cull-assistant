# AI选片助手 v1.5.7

本版处理多脸照片自动选错主体后被跳过的问题，并完善文件夹选择与人工确认操作。

## 更新内容

- 检测到多个人脸但尚未人工选人时，即使已有自动生成的绿框，也纳入“下一张未标记”和“补齐人脸”的待确认范围。
- 在这类照片上首次点击目标人脸，会替换自动选择；已有人工选择保留。手动确认后仍可选择多个合影成员。
- 新扫描记录保存人脸候选数量；旧工作区可在后台通过现有预览补查，不为这项检查解码 RAW，不调用 API。预览缺失或不可读时无法完成该照片的补查。
- 补齐人脸支持 Y 确认、X 不是这个人、P 暂时跳过，操作后跳到下一张，到列表末尾停留。输入框和其他窗口不触发这些快捷键。
- 工作区选择每次从当前工作区路径打开；照片选择返回原有路径，没有历史路径时打开 Windows“此电脑”。失效路径尝试可访问的上级目录。
- 改善 Windows DPI 缩放与子页面说明提示，保留现有工作区、设置及 Lightroom 导出流程。

## 下载与升级

下载 `AI-Photo-Cull-v1.5.7-Windows-x64-portable.zip`，完整解压后运行其中的 `AI选片助手.exe`。包含运行依赖和 Lightroom Classic 插件，无需安装 Python；请勿只复制单个 EXE。

已有用户可通过软件“检查更新”升级。手动升级时保留设置和工作区，不要为升级清空工作区。原片仍保留在原文件夹。

`update.json` 供自动更新使用，`SHA256SUMS.txt` 供文件校验。GitHub 自动生成的 Source code 压缩包是源码，不是 Windows 程序。

## 验证与限制

相关导航、快捷键、多脸确认、旧记录兼容测试及 Windows EXE 自检通过。人物候选仍须人工确认，本版不宣称人物匹配准确率已经完成真实样本校准。
