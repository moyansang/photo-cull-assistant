# AI选片助手 v1.5.8

选片组、清晰度复核、人脸框和 AI 选片整合到主窗口，切换页面时可以继续查看处理进度和日志。

## 更新内容

- **主窗口内切换页面**：顶部导航统一为“主页／选片组／复核／人脸框／选片”。返回主页再进入编辑页时保留本次编辑状态，减少重复打开窗口。
- **共用进度与日志**：统一显示“进度”，主页和复核页让日志使用空余空间；图片编辑页优先展示照片，日志高度随窗口调整。
- **选片组预览**：缩略图根据窗口大小和组内照片数量调整，少量照片使用更大的预览，保留原图比例。
- **人脸框预览**：横图使用宽主图区；竖图把操作按钮放在左侧、照片居中、人脸细节放在右侧。预览背景融入页面，移除细节图上重复的比例文字。
- **设置与按钮整理**：全局检测置信度移到主页并按工作区保存；框选清除和恢复按钮紧随裁切比例。重新扫描仍只处理修改过的照片，裁切比例选择功能保留。
- **选片与导出布局**：导出到 LR 与返回主页放入操作行，调整小窗口中的按钮和列表空间。

本版集中调整界面布局，不新增 GPU 加速，不更改清晰度判定算法、原片处理规则或 Lightroom 导出格式。人物候选仍需人工确认。

## 下载与升级

下载 **AI-Photo-Cull-v1.5.8-Windows-x64-portable.zip**，完整解压后运行其中的 **AI选片助手.exe**。包内包含运行依赖、检测模型和 Lightroom Classic 插件，无需安装 Python。请保留旁边的 `_internal` 和 `lightroom` 文件夹。

已有用户可用“检查更新”升级。手动升级时保留设置及整个工作区，不要为升级清空工作区；原照片仍留在原目录。API Key 使用 Windows 用户凭据管理器保存，换电脑时需重新填写。

`update.json` 供自动更新使用，`SHA256SUMS.txt` 供文件校验。GitHub 自动生成的 Source code 压缩包为源码，不是 Windows EXE。
