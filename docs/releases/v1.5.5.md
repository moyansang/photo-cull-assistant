# AI选片助手 v1.5.5

本版完善日志显示与工作区清理提示，并清理过时入口和无调用代码。包含 v1.5.4 各构建的人脸预览缓存及串行 AI 复核期间提前备图优化。

## 更新内容

- “清空工作区”旁新增“清空日志”，仅清除窗口显示，不删除或修改磁盘日志；新日志继续正常记录和显示。
- 切换工作区、重新定位原照片后清除旧日志显示及排队中的旧消息，不重新载入历史日志。重新启动软件时仍可恢复磁盘日志。
- 扫描、复核或更新期间，“清空工作区”按钮保持可点击，点击后说明暂不能清理的原因。实际清理仍需任务结束并关闭子窗口。
- 后台预备图片失败会记录到完整日志，主页面隐藏诊断内容；日志写入失败不影响复核继续。
- 删除无调用辅助函数、资源属性别名、多余导入和旧重新生成入口，保留旧工作区、旧人脸坐标和断点恢复兼容逻辑。

## 下载与升级

下载 `AI-Photo-Cull-v1.5.5-Windows-x64-portable.zip`，完整解压后运行 `AI选片助手.exe`。包含运行依赖和 Lightroom Classic 插件，无需安装 Python。

软件内“检查更新”可升级，并保留设置和工作区。手动升级请保留 `settings` 和 `workspaces`，不要只复制 EXE。

“清空日志”与“清空工作区”不同：后者会删除当前工作区内全部内容，包括分析、AI 结果、导出结果、缓存和日志；原照片与全局 API 配置不删除。
