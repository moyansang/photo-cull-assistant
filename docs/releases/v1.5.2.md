# AI选片助手 v1.5.2

本版保留现有 CPU 扫描方案，更新任务调度和内存预算；清晰度判断规则不变。

## 更新内容

- 同一并行档位内，照片处理完成后及时补入下一张，减少等待整批照片完成；限制在途任务与待保存结果数量。
- 保留停止、逐张检查点和重启恢复；切换并行档位时隔离旧任务，避免混淆测速结果。
- 区分已有模型线程的处理内存与新线程冷启动内存，保留安全余量、系统预留和低内存降档。
- 完整工作区日志新增可用内存、预算和并行档位诊断信息，不额外显示在主页面日志。

## 验证与限制

- 相关自动化测试与 Windows EXE 自检通过。
- 18 张 RAW、身体检查开启的 1/2/4 并行测试及自动调度测试，逐张清晰度结果一致；765 张全量对比的清晰度结果和分组归属一致。
- 不承诺固定提速比例：本机三次全量扫描约为 28分42秒、25分6秒、28分29秒，受后台负载和内存波动影响，最新内存调整未证明能进一步缩短全量耗时。

## 下载与使用

下载 `AI-Photo-Cull-v1.5.2-Windows-x64-portable.zip`，解压后运行 `AI选片助手.exe`。无需安装 Python，包含 Lightroom Classic 插件。

使用软件内更新可保留设置和工作区。手动解压到新目录时，选择原照片文件夹和已有工作区即可继续使用，不需要清空或重扫。

附件中的 `update.json` 供软件检查更新，`SHA256SUMS.txt` 用于校验下载；GitHub 的 Source code 附件是源码，不是 EXE。
