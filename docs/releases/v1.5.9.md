# AI选片助手 v1.5.9

本版完善工作区恢复、多人主体确认和后台更新检查。

## 更新内容

- 切回工作区或启动软件时，日志显示保存设置、各阶段进度及待处理任务；分组灵敏度、身体清晰度检查、置信度和联系表布局都有记录。
- 根据实际进度推荐继续扫描、AI 复核、生成联系表、继续选片或导出 LR。待提交、请求失败、修改后失效、主动跳过和部分返回分别统计；新发生的复核失败/跳过状态随照片保存。
- 多个候选人脸未确认主体时，本地检查保留“人物待确认”，进入 AI 复核和选片前提示确认合影成员。人脸页显示逐人清晰度结果，修改人物选择后显示“待重新扫描”。
- 自动检查更新在后台运行，不锁住其他按钮。连接中断及 TLS EOF 支持有限重试和备用发布地址；TLS 校验保持开启。网络不可达时仍可能检查失败，但不会阻止照片处理。
- 修复未标记人脸查找与辅助页面布局；API、更新、LR 插件和帮助共用工具窗口，切换时保留 API 草稿。

## 使用说明

下载 **AI-Photo-Cull-v1.5.9-Windows-x64-portable.zip**，完整解压后运行 **AI选片助手.exe**。包内包含依赖、模型和 Lightroom Classic 插件，请保留 `_internal` 和 `lightroom`。

自动更新保留设置和工作区。手动升级请保留设置及整个工作区，不要清空工作区。原照片留在原目录。GitHub 的 Source code 压缩包是源码，不是可运行 EXE。

多人照片仍需人工确认合影成员，本版没有加入自动整组多人追踪。逐人 AI 复核可能产生多次请求。旧工作区没有保存的失败/跳过原因不会凭空补写。导出记录不代表已在 Lightroom 应用。

## 验证

发布前重新运行更新、多人清晰度和恢复摘要相关测试，并执行 Windows 打包 EXE 自检；便携包按程序清单制作，校验 ZIP 完整性、SHA256 及更新元数据。未用新合影数据集评估识别准确率。

`update.json` 用于自动更新，`SHA256SUMS.txt` 用于校验便携包。
