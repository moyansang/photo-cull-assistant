# v1.6.0 · 构建 1

人物补框窗口新增「匹配方式」选择。默认保留原有外观匹配；可选的「人脸特征（实验性）」使用本地 YuNet 检测、五点对齐和 SFace 特征，随便携包提供模型，无需联网或 API Key。

- 支持主参考及最多 5 张人工确认的正参考；展示匹配参考来源。低分、候选近分、参考冲突或与排除参考相似时，交给人工处理。任何候选都不会自动确认身份。
- 保留手动画框、候选切换、Y/X/P、停止、重试和会话恢复。切换模式保留已确认结果，旧后台轮次不能覆盖新结果。
- 特征只存于当前后台任务的有限内存缓存；不会写入工作区或上传。模型缺失或校验失败会明确要求人工处理，不会静默改用外观模式。

已修复回归测试中失效的流程文案预期、缺少审核方法的测试替身，以及测试期间 Tk 对象被后台垃圾回收造成的预览超时；保留行为断言。同时修复关闭窗口时对子控件延时回调重复删除、继而影响后续主题初始化的问题；新增测试在旧代码上稳定复现。布局测试显式指定窗口上限，保持尺寸增长断言，兼容 CI 的小屏幕桌面。Windows 构建流水线现在运行完整回归测试与真实 EXE 自检。

这是实验性辅助功能，余弦分数不是身份概率。现有公开 RGB 人像评估不代表自然漫展合照、复杂遮挡、同服装不同人的完整验证；2、4–6 张参考的门槛尚未独立校准。详见 [证据与限制](../face-identity-mode.md)。

SFace 权重使用 Apache-2.0 许可，YuNet 权重使用 MIT 许可；官方模型、来源和许可随包附带。发布包不包含评估照片或特征向量。
