# AI选片助手 v1.5.4 · 构建 2

构建 2 在等待当前 AI 清晰度复核回复时，由单个后台线程提前准备下一张的人脸细节与上传编码，API 请求仍逐张提交。上传编码缓存上限 32 MiB；每轮最多额外预备 8 张联系表缩略图，生成联系表时复用。停止后不再启动新预备任务，当前图片处理收尾后暂停；继续时使用本次设置。缩略图随预览一起清理，原尺寸细节仍在整轮复核完成后清理。

68 项相关测试及 Windows EXE 自检通过；实际提速取决于缓存命中、图片处理时间与 API 等待时间，未宣称固定提速比例。

本次小更新移除人脸预览中的加载提示，切换照片和选择蓝框时不再显示加载文字；保留后台加载与缓存。已安装 v1.5.4 的用户也可通过检查更新升级。

当前附件对应 [v1.5.4-build2 源码](https://github.com/moyansang/photo-cull-assistant/tree/v1.5.4-build2)；页面自动生成的 Source code 仍对应最初 v1.5.4 标签。

本版在之前的后台加载和未标记照片查找优化上，进一步减少人脸预览切换及 AI 清晰度复核的重复处理。

## 更新内容

- 人脸窗口的图片和检测结果分开缓存，按可用内存确定图片缓存预算，不再仅保留最近 3 份完整结果。
- 返回已看照片时优先复用缓存；调整框选后复用候选检测结果，减少重复检测。图片可先显示，再加载人脸框。
- 空闲时预加载相邻照片及下一张未标记照片，限制后台任务数量，保留快速切图和关闭窗口的保护。
- 新扫描利用已解码的原图，尽量为待复核照片准备原尺寸细节；API 失败重试或更换模型时复用有效图片缓存。
- 人脸或原片等输入改变后重新生成对应细节；缓存损坏时重新生成。
- 暂停及等待重试时保留临时细节缓存，整轮 AI 复核完成后清理；AI 判断结果和已有审计记录保留。

## 使用与限制

下载 `AI-Photo-Cull-v1.5.4-Windows-x64-portable.zip`，完整解压后运行 `AI选片助手.exe`。包含依赖与 Lightroom Classic 插件，无需安装 Python。

软件内更新保留设置和工作区；手动升级请保留 `settings` 和 `workspaces`，不要只复制 EXE。

旧工作区没有新细节缓存时，首次复核仍可能解码 RAW。新扫描可能增加一些细节图片生成时间和临时磁盘占用，以减少后续重复解码；不承诺所有照片切换都立即显示或固定提速比例。内存缓存有容量限制，关闭人脸窗口后释放。没有进行 AI 复核时，已准备的临时细节会保留至复核完成或清空工作区。
