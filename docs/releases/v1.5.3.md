# AI选片助手 v1.5.3

本版解决跨电脑盘符变化导致工作区无法继续使用的问题，并修复编辑界面卡顿、AI 复核缺失预览和清空工作区卡顿。

## 更新内容

- 主页面新增“重新定位原照片”：选择原照片的新位置，按相对路径、文件大小及修改时间核对，更新工作区路径；保留分组、人脸调整、AI 评分与暂停进度。
- 原照片磁盘不可访问时保留暂停任务，提示重新定位；迁移前备份记录，写入失败或中断后可恢复。
- 编辑选片组缩略图与人脸预览改为后台加载，限制队列和缓存；切换照片时忽略过期结果，减少滚动及“下一张未标记”的界面阻塞。
- AI 复核与局部重扫前补建缺失预览；复制工作区后优先使用当前工作区缓存。
- 清空工作区改为后台执行，显示等待状态；暂停尚未完成时明确提示等待当前请求结束并保存。
- 选择新的照片文件夹后立即切换对应工作区，保留手动选择旧工作区的功能。

## 跨电脑使用

停止任务并等保存完成，关闭软件后复制整个工作区。在另一台电脑打开工作区，点击“重新定位原照片”，例如将 `E:\照片\110_PANA` 改为 `G:\照片\110_PANA`。请选择同一批原片；大小或修改时间不一致时拒绝关联。暂停任务有缺失原片时需先补齐。API Key 需要在另一台电脑重新填写。

已完成的分析无需全量重扫。若预览已被清理，会按需补建。没有逐字节校验所有 RAW 内容，也未保证所有电脑上的加载速度；清晰度算法和 CPU 扫描策略未改变。

## 验证

350 项核心测试、36 个独立运行的界面/恢复测试及 Windows EXE 自检通过。覆盖归档工作区、盘符对应的根目录迁移、AI 评分与指纹保留、暂停扫描/复核恢复、错误目录拒绝和写入失败回滚。跨路径测试使用隔离样本，尚未在用户另一台实体电脑上实测。

## 下载与使用

下载 `AI-Photo-Cull-v1.5.3-Windows-x64-portable.zip`，完整解压后运行 `AI选片助手.exe`。包含依赖与 Lightroom Classic 插件，无需安装 Python。

软件内更新保留设置和工作区；手动更新请保留 `settings` 和 `workspaces`，不要只复制 EXE。迁移后建议重新导出 LR 结果，并确保 LR Catalog 中照片路径可访问。

`update.json` 用于自动更新，`SHA256SUMS.txt` 用于校验；Source code 附件是源码，不是 EXE。
