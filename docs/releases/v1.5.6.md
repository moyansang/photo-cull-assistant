# AI选片助手 v1.5.6

本版统一摄影工作台视觉，并包含 v1.5.5 发布后已完成的 API 配置、人物补齐与窗口交互改进。

## 更新内容

- 基于 Tkinter/ttk 和 ttkbootstrap 统一主页、API 配置、选片组、人脸框、人物候选及 AI 选片与导出页面；浅灰背景、深灰文字、低饱和蓝色选中状态。
- 顶部入口统一为主页面、配置 API、检查更新、LR 插件、帮助。Alt+1～4 和 F1 保留，快捷键移至悬停提示；主页六个流程按钮保持同排。
- 人脸框导航第一行：上一张、下一张、重置当前裁切；第二行：上一张未标记、下一张未标记、补齐人脸。照片预览采用深灰底。
- 支持以参考人物在工作区查找跨组选脸候选，经人工确认后采用；完善确认状态与直接框选、移动操作。
- 修复 API 自定义预设及高级设置切换时的窗口问题，更新千问模型预设。
- 改善关闭 AI 选片准备窗口的处理，并复用未变更的选片任务状态。

本次视觉调整不改变清晰度算法、照片处理规则、工作区数据格式或 Lightroom 导出行为。

## 下载与升级

下载 `AI-Photo-Cull-v1.5.6-Windows-x64-portable.zip`，完整解压，运行其中的 `AI选片助手.exe`。包含运行依赖及 Lightroom Classic 插件，无需安装 Python。请勿仅复制单个 EXE。

已有用户可在软件中检查更新。手动升级请保留设置和工作区，不要使用“清空工作区”作为升级步骤。

`update.json` 用于自动更新，`SHA256SUMS.txt` 用于校验。仓库保留源码，GitHub 自动生成的 Source code 压缩包不是 Windows 程序。

## 验证

相关界面回归测试及 Windows EXE 自检通过。已检查真实 Tk 桌面窗口、小窗口、长文本、空状态、错误状态和放大字体；实际 Windows 缩放为 125%，额外字体倍率模拟不等同真实多屏 DPI 切换测试。
