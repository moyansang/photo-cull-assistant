# RAW 读取、解包与显影分段计时

本次只增加本地诊断，不改变 GPU 后端、解码参数或清晰度阈值。
新增数据仍写入工作区 `logs/session.log` 的 `[扫描诊断]` 行，主页面隐藏这些详细行。

## 为什么不能只计时 imread 和 postprocess

本地 rawpy 0.27.1 的 `imread()` 调用 `open_file()`，不立即解包像素。
`postprocess()` 通过 `dcraw_process()` 调用 `ensure_unpack()`，可能同时包含解包。
因此只计时两个函数会低估解包、高估显影。

当前在 `postprocess()` 前访问 `raw.raw_image`，触发幂等的 `ensure_unpack()`。
这是底层像素的数组视图，不复制完整像素，也不再次解包已经解包的图像。
显影参数继续为相机白平衡、全尺寸、关闭自动增亮、8 位输出。

| 诊断名称 | 范围 |
|---|---|
| raw_full_open | 打开 RAW、解析文件信息 |
| raw_full_unpack | 按需读取并解包原始像素，含相关 I/O |
| raw_full_postprocess | 解包完成后的显影及返回 RGB 数组 |
| raw_full_decode | 上述完整流程及资源释放的合计 |
| raw_preview_open | 预览阶段打开 RAW |
| raw_preview_extract_thumb | 提取内嵌预览，不等于完整 RAW 显影 |
| raw_preview_unpack / raw_preview_postprocess | 无可用内嵌预览时的解包及半尺寸显影 |

父级 `raw_full_decode` 已包含各子项，不能与子项再次相加。
`raw_preview_half_decode` 同样包含预览回退的两个子项。
正常并行扫描的统计是各照片累计墙钟耗时，不能除以扫描总墙钟时间当作耗时占比。

## 复现

```powershell
.venv/Scripts/python.exe tools/benchmark_raw_stages.py `
  --input D:/test-raw `
  --output build/raw-stages-new
```

输入目录只能包含 1 至 80 张 RW2 图片；输出目录必须不存在，并与输入目录分离。
固定照片串行为 1，保留默认 RAW 内部线程；关闭身体检查及 API，使用新工作区，
调优记录也隔离保存。不会重用或覆盖用户工作区、配置和原片。
结果保存到输出目录 `report.json`，包括各阶段累计秒数、完整扫描时间及照片判定。
可通过 `--baseline` 指定已有、包含 `verdicts` 数组的基准报告，逐项比较结果。
测试前后核对原片大小和修改时间；没有清空操作系统磁盘缓存，不是冷盘测试。

## 2026-09-15 实测结果

Ryzen 7 5800H（16 逻辑处理器）、约 16 GiB 内存；rawpy 0.27.1。
输入原 80 张 RW2 测试集，扫描完成墙钟时间 130.43 秒。
80 张全部提取内嵌预览，76 张进入全尺寸解码，4 张没有可靠人脸而跳过全尺寸解码。
没有预览半尺寸显影回退，也没有 API 请求。

| 全尺寸 RAW 流程（76 次） | 累计耗时 | 占 RAW 完整流程 |
|---|---:|---:|
| 打开文件及信息解析 | 0.02 秒 | 0.02% |
| 按需读取、解包原始像素 | 14.62 秒 | 15.79% |
| 解包后的显影及 RGB 数组输出 | 76.81 秒 | 82.92% |
| 其余上下文及资源释放开销 | 1.18 秒 | 1.27% |
| 合计 | 92.63 秒 | 100% |

外层“RAW/原图解码”阶段为 95.49 秒，比上表多的部分包含 PIL 图像构造等工作。
原有整场扫描日志：预览 4.8 秒、人物检测 20.7 秒、清晰度分析 2.7 秒、
保存 0.4 秒、分组 1.7 秒。详细报告里的 `photo_stage_seconds` 仅为逐照片阶段，
不包含扫描其他位置再次进行的人物检测等工作，不能替代整场统计。

**本批照片的主要成本在显影，不是 RW2 解包。** 显影约占整个串行扫描的 58.9%。
这表明值得研究显影加速，但不能把这 76.81 秒全部当成可消除的 GPU 时间：
需要另测算法、传输、显存和并发的实际成本。本次未实施或测量 GPU 加速。
串行阶段占比也不能直接套用到日常多照片并行运行中。

与已有 80 张基准报告逐项比较，分组、人脸状态、清晰度指标及弃置判定完全一致；
原片大小与修改时间未变。有效报告：`build/raw-stages-80/report.json`，
详细日志：`build/raw-stages-80/workspace/logs/session.log`（均为忽略目录，不提交照片）。
