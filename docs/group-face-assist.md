# 同组人脸辅助补框

在“检测／调整人脸框”中手动框好一张漏检照片，再点“补齐本组人脸”。第一版只处理同组缺少定位框的照片；已有框、手动隐藏、明确取消人脸选择的照片不会被覆盖。

1. 等待后台逐张查找；可点“停止查找”保留已完成的候选。
2. 在列表选择照片，查看蓝色虚线候选及局部放大图。
3. 点击框内选中为黄框，可上下左右拖动，滚轮每格微调约 2%。需要重画时点“手动调整”；没有候选框时可以直接拖动画框。
4. 每张确认后点“确认此框”，也可勾选采用。修改框后需再次确认。
5. 点“采用选中候选”合入原窗口的编辑草稿，再点“重新扫描修改过的图片”保存并进行本地重算。

取消候选窗口不会写入本轮候选。照片、分组或已有编辑在计算期间变化时，会拒绝受影响的旧候选。缺失预览不会为本轮匹配自动批量解码 RAW。

补框和本地重算不调用 API。正常顺序是先调框，再由主页启动 AI 复核；如果已经复核过又回来改框，保存时提示已有结论需要重新复核的数量。

局部检测沿用全局人脸检测置信度，并关闭旋转救援；模板匹配门槛独立。当前为初始阈值，尚未完成真实漏检样本的准确率校准，所有候选需逐张确认，未开放批量采用。匹配到头部不代表脸部清晰，也不属于模型训练。
