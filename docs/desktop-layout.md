# 摄影工作台布局

使用 Python、Tkinter、ttkbootstrap，界面调整不修改检测、扫描、工作区格式或导出规则。

## 共用结构

- 顶部工具入口保留主页面、配置 API、检查更新、LR 插件、帮助，以及 Alt+1～4、F1。
- 主窗口保留固定顺序的页面入口：主页、选片组、人脸框、复核、选片。
- 选片组、复核、人脸框、选片嵌入主窗口；切换页面保留编辑草稿、当前选择及后台任务。替换工作区或结果前确认未保存的人脸修改。任务运行时仍可返回主页查看日志，编辑入口暂停使用。
- 主页“AI 复核”和顶部“复核”都只打开准备页，不自动启动任务或发送请求。用户在页内主动点击“开始 AI 复核”后复用既有任务入口，在共用底栏查看日志与停止、继续处理。重复导航复用页面，任务运行时仍可进入查看。
- 浅灰背景、白色表单与导航、深灰照片画布、低饱和蓝选中状态；颜色与字体集中在 `ui_style.py`。
- 主页六个流程按钮在宽度足够时同排，窄窗口按整项换行。构建 13 取消主页内部滚动画布，路径标签与输入同行，表单使用自然高度，日志独立滚动；不固定表单高度或截断底部操作。
- “打开联系表目录”与右侧“打开选片结果”作为一组换行。结果入口使用当前工作区导出路径解析，打开 `lightroom_results.json` 所在目录，不创建导出或启动 AI 任务。
- 较矮的高缩放窗口仅压缩主页表单和共用按钮的字体（上限 18 像素）及间距，其他编辑页字体保留原缩放。主页下拉框与数值框阻止滚轮改值，保留点击、键盘与箭头操作。
- 较矮主页同时压缩顶部导航与任务状态文字，推荐下一步合并到日志标题行；数字输入保留足够字符宽度，让四项参数尽量同行并为至少一行日志留出空间。切到其他编辑页后导航恢复原样。
- 帮助与悬停说明承载详细文字；关闭按钮不改变各页面原有保存语义。
- 内容区下方保留控制栏、推荐下一步、统一“进度：”及日志。主页和复核按内容高度布局，剩余空间供日志伸展；照片页面优先分配预览高度，日志随窗口高度调整行数。扫描、复核、选片和更新复用进度条。

## 内容组织

选片组以紧凑组列表和当前组照片为中心。人脸页以大预览和侧栏细节为中心，保留两行导航：上一张／下一张／重置当前裁切，上一张未标记／下一张未标记／补齐人脸。人物候选仍须人工确认后采用。选片结果将照片与对应回复、星级、弃置状态并排展示。

## 验证范围

使用隔离设置与合成图片检查桌面窗口、短窗口、长路径、空状态、错误文字以及放大字体布局。缩放模拟不能替代在多种真实显示器 DPI 下的完整兼容性测试。测试不调用付费 API、不读取用户密钥、不修改真实工作区。

嵌入页面统一使用“返回主页”隐藏页面并保留草稿；选片组与合并按钮同排，复核与继续处理同排，人脸框放在人脸细节下方，选片页与导出按钮并排。API 页导出与返回放在批次操作行最右侧；较矮窗口可折叠选片偏好，避免挤掉批次列表。

选片组缩略图按内容区宽高与组内照片数适配：一两张占用一行的大预览，多张选择网格；大组保留可读尺寸并滚动。横竖图等比例完整显示并居中，只对可见区域解码，缓存键包含预览尺寸。
