# 摄影工作台布局

使用 Python、Tkinter、ttkbootstrap，界面调整不修改检测、扫描、工作区格式或导出规则。

## 共用结构

- 顶部工具入口保留主页面、配置 API、检查更新、LR 插件、帮助，以及 Alt+1～4、F1。
- 核心窗口增加固定顺序的页面入口：主页、选片组、复核、人脸框、选片。
- 切换页面遵循当前窗口的关闭和未保存确认机制；后台任务未结束时不切换。
- 复核入口打开准备页，不自动发送请求。点击开始后复用既有任务入口，在主页查看日志与停止、继续处理。
- 浅灰背景、白色表单与导航、深灰照片画布、低饱和蓝选中状态；颜色与字体集中在 `ui_style.py`。
- 主页六个流程按钮同排。照片列表可滚动，窗口主要操作固定可见。
- 帮助与悬停说明承载详细文字；关闭按钮不改变各页面原有保存语义。

## 内容组织

选片组以紧凑组列表和当前组照片为中心。人脸页以大预览和侧栏细节为中心，保留两行导航：上一张／下一张／重置当前裁切，上一张未标记／下一张未标记／补齐人脸。人物候选仍须人工确认后采用。选片结果将照片与对应回复、星级、弃置状态并排展示。

## 验证范围

使用隔离设置与合成图片检查桌面窗口、短窗口、长路径、空状态、错误文字以及放大字体布局。缩放模拟不能替代在多种真实显示器 DPI 下的完整兼容性测试。测试不调用付费 API、不读取用户密钥、不修改真实工作区。
