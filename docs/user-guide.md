# 使用指南 · v1.5

[返回首页](../README.md) · [常见问题](faq.md)

## 扫描、修正、复核、选片

1. 选择照片文件夹与工作区。建议工作区放在照片目录外，可跨 EXE 版本继续使用。
2. **扫描图片**只负责本地初筛、检测与分组，不调用 API，不生成联系表。
3. 用**编辑选片组**调整组；用**检测/调整人脸框**检查漏框、背景误框与裁切。框外拖动可重新框选，点击绿框内部变黄后拖动位置，滚轮微调范围。裁切比例与位置逐张记忆，检测置信度全局生效。
4. 人脸窗口的**重新扫描修改过的图片**只重新判断改动照片，不重做全部分组；相关旧 AI 清晰度结果会失效，之后可再次复核。
5. 按需执行 **AI 复核**。没有 API 可以跳过，待确认照片仍能导出到 LR，但不进入正式选片。单张请求失败不停止整轮，结束时选择仅重试出错照片或跳过。
6. **生成联系表**仅排版，不重做本地筛查或调用 AI。
7. 打开 **AI 选片与导出**，选择 API 或网页提交；在结果表查看照片、AI 理由、星级与弃置。右下角导出后到 Lightroom 看原图复核。

## API 与网页提交

在主页面配置 API，填写预设的 Key，或者用自定义服务地址、模型和超时。支持 OpenAI-compatible Chat Completions；既可填接口前缀，也可填完整 `/chat/completions` 地址。

- **全 API**：本地修正 → AI 复核 → 联系表 → API 选片。
- **API 复核 + 网页选片**：保留主页面 API 配置，在选片窗口切换网页页即可；已完成的有效复核不会因此重跑。
- **全网页**：不配置 Key，本地修正与联系表完成后走网页页；清晰度待确认照片导出到 LR 人工检查。

网页页支持 Ctrl/Shift 多选或全选未完成批次，合并准备后复制一份提示词，上传对应图片，粘贴整份模型回答。平台图片数量/文本长度受限时分几次合并。编号、JSON 格式和照片必须对应，异常回答会留存供检查。

改变选片偏好后，使用 API 页的**重新提交**开始新一轮。“精选照片再选一轮”只选择当前有效、未弃置的 4–5 星候选；API 页会衔接提交，网页页会准备网页材料。

## 照片增删与恢复

- **删除部分照片**：重新打开同一工作区时移除缺图记录，保留其余分析和分组；重新生成联系表再选片/导出。
- **新增照片**：日志提示新增文件数，点扫描图片只处理新增或配对变化的照片。旧分组保留，新增照片另行分组，可手动合组。
- **RAW 被删但 JPG 仍在**：JPG 会成为待扫描输入；不能直接沿用已删除 RAW 的清晰度判断。
- **没有新增文件时点击扫描**：仍是完整扫描，可用来按新设置重做本地筛查。
- **原片同路径内容变化**：旧分析不能被当作有效结果，需重新扫描。
- **整个原片目录/磁盘不可访问**：先恢复磁盘连接或正确路径，不会按“全部删除”清空工作区。

以上针对已完成的扫描记录。正在处理/中断任务中原文件集合变化时，仍会终止该中断任务；已发布的上一轮工作区可以恢复。不要在任务运行中整理原照片。

## 停止、继续和日志

停止会等待已派发的少量照片完成并保存，不强行终止 RAW 解码。重新打开后可继续同一阶段；已完成部分保留原设置，后续用新设置。扫描和更新共用进度条。

主页面显示进度、错误、结果摘要；完整诊断统一保存在工作区 `logs/session.log`，旧布局可能是根目录 `session.log`。CPU 并行阶段耗时为累加工作时间，可能大于实际等待时间。

## 工作区与设置

便携程序全局配置在 EXE 同级 `settings/`，每个照片目录默认对应 `workspaces/目录名-编号/`。API Key 保存在 Windows 凭据管理器；复制程序不等于复制密钥。

| 内容 | 作用 |
|---|---|
| `scan-session.json`、`groups.json` | 扫描状态与分组 |
| `workspace-settings.json` | 此工作区参数和逐张人脸设置 |
| `ai_project.json`、`ai_tasks/` | AI 任务、结果和提交快照 |
| `contact_sheets/` | 联系表 |
| `exports/lightroom_results.json` | LR 导出；旧布局可能在根目录 |
| `previews/`、缓存目录 | 可重建的预览与分析缓存 |
| `.workspace-archive.zip` | 自动整理后的状态归档 |

关闭或切换工作区时，软件校验归档后清理可重建缓存，保留联系表、AI 提交材料和导出结果。再次选择时恢复状态，预览按需重建。正在进行的处理任务所需数据保留；无法整理的原因写日志。

**清空工作区**会清除该工作区的分析、设置、日志和导出等内容，操作前有确认；不是清理缓存按钮。程序禁止清理与原片目录重叠或包含程序文件的工作区。

## 安装与升级

优先用应用内检查更新。可勾选“不再自动检查更新”，之后仍能手动检查。更新下载校验哈希及程序清单，仅替换程序文件；自定义同名文件冲突时会中止。

手动升级时完整解压新版，选择原有工作区。不要只复制 EXE，也不要为了更新删除工作区。LR 插件需在增效工具管理器中重新加载或指向新版包的插件目录；LR 原图路径需要保持一致。

GitHub Release 中的 `update.json` 给自动更新器使用，不是选片结果；`Source code` 是开发源码，普通使用者下载便携 ZIP。
