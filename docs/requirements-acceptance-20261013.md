# 需求验收矩阵（2026-10-13，源码候选）

本表区分实现、连接路径证据与产品验收。所有 Tk 控件替身测试均不是实际窗口渲染；本机没有可用 DISPLAY。未发布、未部署、未替换 Windows 程序。

| 用户需求 | 状态 | 实现与证据 | 仍需验证/补齐 |
|---|---|---|---|
| 扫描前手动人像/风景，续扫固定模式 | 已实现、逻辑验证 | app → ProcessingJob → screening；test_pipeline_redesign 模式续扫/风景集成 | 真实下拉框操作与 Windows 旧设置迁移 |
| 同图 JPG 优先、坏 JPG/仅 RAW 回退，无半尺寸层 | 已实现、部分真实格式验证 | image_decode/shared_decode；test_image_decode_policy、test_image_codec_integration；真实 CR2/NEF/HEIF/AVIF | 全部 RAW 相机/压缩变体，尤其本用户 RW2 新策略 |
| 证据不足才完整 RAW，不因分数接近升级 | 已实现、逻辑验证 | face_focus ROI/pixel/细节证据 → refine_analysis_image；decoder tests | 96/56px 等阈值尚未真实标注校准 |
| BMP/HEIF/AVIF、多 RAW 扩展名适配 | 部分完成 | 扫描能力、真实部分解码、坏文件占位恢复测试 | 枚举扩展名不保证全机型；HEIF 分发许可/维护门槛未关闭 |
| 复用解码、限制缓存和并发 | 已实现、逻辑验证 | shared_decode 同图嵌套；LRU128MiB、原生解码信号量、扫描并发限制 | 原生库额外峰值内存与低内存压力测试 |
| 全工作区无时间/目录门槛、哈希+灰度结构分组 | 已实现、逻辑验证 | dHash索引+块SSIM+固定代表；grouping/group_store测试；新增照片跨目录入原自动组 | 真实分组精度、误合并/误拆分标注评估；不是跨多个独立工作区合并 |
| 防链式串组、手工组/稳定ID/旧工作区 | 已实现、逻辑验证 | 代表一致性、v1/v2组存储、人工组保护、Linux迁移回归 | Windows真实旧工作区备份副本验收 |

| 脸与身体同人关联、不混淆多人 | 保守实现、连接路径验证 | test_subject_flow_acceptance：public screen_assets同时支持selected_faces/manual_face+人体框；姿态头框唯一对应脸时归入同一人物，身体问题仍单列；歧义重叠待复核 | 几何关联不是身份识别；阈值未真实标注校准，遮挡/交叠需人工确认；仅选身体时不自动追加未知人脸 |
| 风景整图不框选、不误杀低纹理/景深 | 部分完成 | 整图分块纹理门控；keep/review；风景与AI输入测试 | **自动推荐弃置未实现可靠校准，只保留/待复核；属于待完成能力** |
| 本地仅推荐保留/弃置/待复核，不评星 | 已实现、逻辑验证 | effective_decision、本地聚合、组建议与LR导出测试 | 本地阈值准确率尚未校准 |
| 人工 > 有效AI > 本地，同源显示导出 | 已实现、连接路径验证 | 真实扫描 → ReviewProject → 模拟HTTP响应 → 人工覆盖 → Lightroom结果；test_results_wired_acceptance | 实际Lightroom插件导入/现有星级保持 |

## 开源研究与可复用代码

逐模块 research-*.md 含官方来源、许可证、依赖代价与未采用理由；research-source-revisions.json 记录本次参考仓库 HEAD。没有复制第三方应用源代码。复用已有 Pillow/rawpy/OpenCV/模型 API，新增解码专用 pi-heif；分组、状态调度与查看器独立实现。研究 HEAD 不等于安装的包版本，二进制版本另记。pi-heif 停更及 LGPL 库实际版本与附带源码链接不一致是发布阻塞，不因源码测试通过而忽略。
