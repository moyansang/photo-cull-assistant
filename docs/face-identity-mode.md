# 人脸特征匹配（实验性）

入口：检测/调整人脸框 → 框选参考人物 → 补齐人脸 → 查找方式「人脸特征（实验性）」。
旧「外观（颜色/纹理）」保留。查找期间先停止并等待结束，才能切换；已确认的框保留，未确认候选重新计算。

YuNet提供真实五点，SFace离线CPU对齐/提取特征，多参考取最大归一化余弦相似度。分数不是身份概率，不自动确认或采用。
无权重、校验失败、无可靠脸、多脸参考、低分、参考不一致、负参考冲突、近分候选均交给人工处理，不自动切回外观算法。目标图可以包含多个人脸；参考框必须明确包含一个人。最多8个检测脸，超过则人工核对。

实验默认门槛：1张参考0.52；2–3张0.53；4–6张0.56。只有1/3参考在小规模独立人像集验证过；其他数量是保守产品规则，未独立校准。
最高与第二候选差距小于0.05要求手选；参考两两余弦低于0.52也要求人工检查。它们是新增保守保护，不是从最终测试集重新调出的准确率结论。
Y确认才成为正参考；X排除当前框作为负参考；P跳过不成为参考。选择候选不等于确认，确认后仍需「采用选中候选」。修改参考在下一轮生效，旧线程消息不覆盖新一轮。

模式和人工审核记录保存在既有工作区反馈文件中，兼容旧文档。特征仅保留在当轮后台线程内存，结束清空；像素内容、模型哈希和预处理版本参与缓存键，不将特征写入照片、设置或反馈。

原型验证：身份级分离12人校准/12人最终测试；近景RGB跨日四候选单/三参考Top1为107/108、108/108，冻结原型门槛正确建议105/108、缺席误建议0/108。完整原型每条件只有108例且反复使用12人，不能外推为漫展保证。
正式模式增加参考冲突和0.05近分保护、允许目标图多人；因此原型数字不能视为正式集成后的独立准确率。后续测试仅作回归，需另有未使用困难负例验证。
