# 中性浅灰工作台（本地构建 6）

范围仅主页、API 配置和人物候选页。处理算法、API 请求、工作区持久化、LR 导出未改动。

## 样式规范

颜色与命名字体集中于 ui_style.py；正文 10pt，辅助 9pt，快捷键 8pt，标题 11pt 加粗。优先 Microsoft YaHei UI，回退系统字体。
背景 #F3F4F5，输入/列表 #FFFFFF，文字 #202428，次要文字 #5B636B，强调 #245DB5，选中 #E5EDFA，照片底 #303030。
间距采用 4/8/12/16 档。主页六按钮同排同权；API 保存和候选采用为主按钮，清空工作区为危险色。
使用独立 Cull.* 样式，从 Clam 复制需要的控件元素，保持原全局主题与其他页面样式；不修改 Tk 默认字体或全局控件构造函数。
顶部 Alt+1～4/F1 保留，键盘焦点使用边框区分。候选参考文件名和当前候选文件名提供悬停全文，错误文字换行，列表内部滚动。

## ttkbootstrap 评估

隔离测试 ttkbootstrap 2.2.3（build/theme-eval，不加入产品依赖）。基本控件兼容，但主题及 Text/Canvas 背景作用于整个解释器，标准 ttk 命名样式在换肤时可能重置，多 Tk 根生命周期需额外适配。与只改三页的范围不符，本轮采用原生 scoped ttk.Style。
参考 https://www.ttkbootstrap.org/en/latest/ 及该隔离包源码/实际运行。
设计参考 UI UX Pro Max 的语义颜色、字体层级、一致性，Impeccable 的层级、状态、平台适配和边界评审；未安装或执行这两个设计技能的脚本。

## 验证记录

真实 Python/Tk Windows 窗口截图位于 build/visual-a；使用独立临时设置和生成的示意图，没有调用真实 API 或使用用户工作区。截图不是 HTML，也不证明人物识别准确率。
Windows 实际 DPI 120（125%）。100/150/200% 使用 Tk scaling 模拟字体倍率，不等同修改 Windows 系统缩放；未验证真实多屏拖动/每显示器 DPI 切换。
覆盖主页 960x640、API 740x560、候选 1100x650，以及放大字体后最多 1400x780 的窗口。检查六按钮同排、操作按钮边界、长文件名/路径、API 长错误、候选空状态、缺图状态。
桌面控制插件初始化失败，改为测试进程打开实际窗口并使用 Pillow 屏幕截图。人工检查截图与控件边界断言组合验收。
