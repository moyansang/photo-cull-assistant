# 页面布局与说明统一方案（本地构建 5 已实施）

## 目标

所有操作按钮与当前照片在窗口内可见，取消整页纵向滚动。照片列表、批次列表、日志等无限长度内容仍在各自区域内滚动。窗口按屏幕可用区域及系统 DPI 居中，预览区随窗口缩放，不靠不断缩小字体容纳内容。

## 检测／调整人脸框

```text
检测／调整人脸框                                      [帮助]
照片名 · G002 · 2/13             [当前人物 ▼] [裁切比例 ▼]
置信度（全局）[0.80 数值输入]
┌─────────────────────────────┬────────────┐
│                             │            │
│          照片预览            │ 人脸细节   │
│                             │            │
└─────────────────────────────┴────────────┘
[上一张] [下一张] [上一张未标记] [下一张未标记]
[恢复本张自动选脸] [去除所有框选] [重置当前裁切] [补齐人脸]
修改了 N 张                     [重新扫描修改过的图片] [取消]
```

- 顶部设置、底部操作固定，中间预览使用剩余空间；小屏时两侧预览仍并排，优先缩减细节栏宽度。
- 全局置信度从长滑块改为紧凑数值输入；保留现有限制及作用范围。
- 颜色含义、置信度解释、多人说明和操作教程移至说明窗口。
- 去除所有框选作用于当前照片：清除已选人物和手动画框；蓝色检测候选保留以便重选。
- 重置当前裁切恢复当前编辑人物／照片的范围、偏移和比例，不取消选脸。

## 补齐人脸

顶部参考照片、进度与停止查找；中部候选列表、照片、细节三栏；底部确认、跳过、采用、取消固定可见。
直接拖拽空白处画框；点击框变黄后拖动，滚轮微调。任何几何修改撤销确认。状态优先显示已确认，采用后进入主编辑草稿，最终通过主编辑页保存。

## 全软件统一说明

每个页面右上角有“帮助”，按当前页面呈现用途、操作步骤、保存时机与注意事项。长说明不再常驻占空间；进度、错误、当前选择等必要状态仍保留在页面。
鼠标停留约 600 毫秒显示按钮浮窗说明，移开、点击或关闭窗口即消失；浮窗不抢焦点，自动避开屏幕边缘。禁用按钮也解释当前为何不可用。键盘 F1 打开当前页说明。

## 各页面布局

- 主页面：路径和基础设置在上，流程按钮居中，进度及日志在下；日志内部滚动，页面不滚动。
- AI 选片：偏好紧凑排列；API 选片、网页选片、选片结果保持标签页；底部导出与关闭固定。
- API 配置：基础设置与高级设置用标签页分开，测试和保存固定在底部，切换不改变窗口位置。
- 编辑选片组：分组列表、当前组照片分栏，操作按钮固定；只滚动列表和缩略图区域。
- 其他配置及更新窗口：复用同一说明和悬停机制，危险操作说明清楚实际范围。

## 代码构建

1. 新增 ui_help.py：页面说明数据与控件说明映射，集中维护中文文案。

4. 分页迁移 crop_dialog.py、group_face_assist_dialog.py，再处理 app.py、ai_review_ui.py、ai_api_dialog.py 和 group_editor.py。
5. 验证 1280×720、1366×768、1920×1080，覆盖 100%、125%、150% DPI；检查底部按钮可见、图片比例、弹窗位置、悬停关闭清理、旧功能保存行为。

本地构建 5 已实施以上布局与共享帮助。顶部快捷栏为主页面 Alt+1、配置 API Alt+2、检查更新 Alt+3、LR 插件 Alt+4、帮助 F1；主页面六个流程按钮同排。补齐人脸不再选择组号，以当前选中人物作为参考，搜索整个工作区未标记照片，用候选缩略图核对，所有结果均需人工确认。
