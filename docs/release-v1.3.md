# v1.3

- 扫描先通过两张照片估算内存，再根据 CPU 和可用内存在 1/2/4 张之间调整并发；日志显示各阶段耗时。
- 每张完成后增量保存，减少整份扫描记录重复写入；支持停止和重启恢复，继续时剩余照片使用新设置。
- 去掉“手动选人脸”勾选项，直接拖拽框选；点击绿框内部变黄后可上下左右移动，框外拖拽可重新框选。
- 修复存在待提交、过时或尚未重新评审的 AI 结果时，关闭软件不压缩工作区、不清除缓存的问题。已有评分、回复和待处理状态原样保存；活动扫描任务所需恢复缓存仍保留。
- LR 插件按 RAW、JPG 等格式显示实际匹配和未匹配数量。

解压完整便携包后运行 AI选片助手.exe。应用内部版本号为 1.3.0，发布标签为 v1.3。
LR 插件位于包内 lightroom/PhotoCullAssistant.lrplugin，需要在 Lightroom 增效工具管理器中更新已安装的插件，才会显示新的分类统计。

旧工作区可继续使用。新版本创建的中断任务使用新版增量记录，请使用新版本继续处理。
