# 分组页“选择检查人物”入口

当前云端候选基于已恢复的第一轮源码。第三轮ADNet只保留独立研究脚本，本入口没有接入新模型，也不依赖丢失的第二轮代码。

## 使用闭环

1. 在分组页单击当前照片，查看原因：主体范围待指定/重新确认、清晰度或局部证据待复核、或需重新扫描。
2. 点击“选择检查人物”，进入已有框选页并定位这张照片。没有选中照片时禁用；被筛掉、过期、同名歧义、工作区变化、任务忙碌时不改开其他照片。
3. 在原框选界面选/补要检查的人物。入口本身不确认、不保存、不重扫、不传给同组其他图；已有编辑页草稿保留。
4. 使用原保存按钮明确确认后，继续原有重扫与重新判断自动组流程，人工组保留。人工评级/取舍优先规则不变。框选页保存会销毁旧分组页，本入口不回调已销毁页。

选好人物不等于画面清晰。手工框内仍需真实检测关键点；关键点不足、像素不足、源区域不足等仍可能要求检查原图。本页只展示保存证据，不能单凭旧标签声称当前人工确认有效。旧AI复核过期单独说明，不把它误当本地刚重扫的测量也已过期。

## 实现边界

- GroupEditor新增可选on_select_subject(asset)，按当前可见精确对象路由。重复stem卡片用独立对象tag；隐藏已选对象不会回退到同名另一张。
- App._open_group_subject核验当前scan对象、完整路径唯一性、任务状态和工作区；新页直接initial_asset起步，已有页show_asset保留草稿。
- CropDialog只新增定位能力，未修改save、确认摘要、选框数据格式或保存/重算语义。
- 其他页面布局和主题不变；分组成员/算法/拆分合并保存逻辑不变；同名照片无法唯一定位时，拆分入口明确拒绝而不修改分组；未新增身份识别或跨照片传播。
