# 人物候选审核与离线评测

本地构建 3 保留原始排名公式及候选门槛，不把颜色纹理分数视为身份概率。
接近门槛、相近候选、与反向参考冲突、灰度/低纹理证据或只有模板证据时，结果为“不确定”，不预选框。
可从“待核对候选”选择一个候选或直接画框，再按 Y 确认；选候选不会自动成为正参考。
没有候选不证明人物缺席，也可能漏检；有候选也不证明身份相同。已确认决定继续恢复，待确认旧框重新查找。
X 排除、P 跳过、停止、手动修改和最终采用仍保持独立；未确认内容不会自动采用。

## 可复现评测

从官方来源自行下载 AT&T/ORL（脚本不联网、不自动下载）：
https://www.cl.cam.ac.uk/research/dtg/attarchive/facedatabase.html

署名 AT&T Laboratories Cambridge / Olivetti Research Laboratory。官方提供下载并要求署名，属于公开使用说明，非现代 SPDX 许可证；不要随代码分发图像。
ZIP：https://www.cl.cam.ac.uk/research/dtg/attarchive/pub/data/att_faces.zip
SHA256：509d763bd2276aa054d260d7f1000e8be212738134f2f83d8ff13bc2adf1c8ec

```powershell
python tools/evaluate_person_orl.py --data <解压数据目录> --output <仓库外结果目录>/validation --partition validation
python tools/evaluate_person_orl.py --data <解压数据目录> --output <仓库外结果目录>/test --partition test
```

可设置 AI_CULL_BODY_MODEL_DIR 指向本机已校验的模型目录；缺失模型会记入报告。
固定种子 20261008。validation 使用 s1–s20，test 使用 s21–s40；候选池不跨身份分区。
每个身份保留 3 张参考，其余 7 张查询，单/三参考共用互斥留出图，随机四候选，包含同数量目标缺席组。
输出划分和哈希、每组候选/分数、失败记录和图片、每场景 Top-k、空返回/错误建议、运行时间及不确定选择次数。
--partition all 可复现最初 40 人协议，不能用它调参再将 test 当作未知数据。

主要指标是已知候选裁图的外观排序：原生产排序函数配合临时的已知框和按原裁图边界提取特征，模板关闭；完整框是裁图范围，不是人工精确人脸真值框。
另运行未打补丁管线烟测，只计异常、是否产生候选及来源，不把非空结果当定位正确。
合成遮挡把所有查询候选的下部30%置灰；不是自然遮挡场景。
灰度紧裁脸不能证明彩色、服装、侧脸或漫展完整检测性能，所谓上半身区域实际是裁脸下缘。

## 验证边界

本次改进只宣称安全审核行为与可解释性，不宣称识别泛化提升。排名门槛和权重未按 ORL 改动。
新灰度/纹理诊断是信息完整性提示，不是校准过的身份拒识阈值。即使没有诊断原因，目标仍可能缺席。
本轮之前已浏览整个 ORL 基线结果，所以现在的 validation/test 分区只是复现隔离机制，不能追认成从未查看过的测试集。
未来如拟合拒识阈值，须用独立验证集定阈值并冻结规则，另取未参与调参、未预先查看的最终测试集（优先按身份和拍摄会话隔离），报告误接受/误拒绝与分场景结果。
不得在本次测试集挑阈值后使用同一批数据宣称提升。照片、结果与本机绝对路径不提交到源码。
