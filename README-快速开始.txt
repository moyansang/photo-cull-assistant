AI选片助手 v1.2.1 快速开始

1. 完整解压后运行 AI选片助手.exe，选择照片目录和独立工作区。
2. 点击“扫描图片”：本地检测人脸、初筛虚焦／抖动并分组，不调用 API。
3. 使用“编辑选片组”和“检测/调整人脸框”。人脸窗口点击“重新扫描修改过的图片”，只重新判断修改照片的清晰度，保留手动分组。
4. 按需点击“AI 复核”。明确模糊的自动标记弃置，数量写入日志；仍不确定的保留“清晰度待确认”。未配置 API 可跳过。
5. 点击“生成联系表”。此步骤不重新扫描或请求 AI。
6. 点击“AI 选片与导出”：可选 API 提交或网页提交。网页仍可用于不配置 API 的场景。
7. 查看照片、AI 理由、星级和弃置状态。导出到 LR 将本地弃置、AI 清晰度弃置和 AI 选片结果合并，使用随包 LR 插件导入。

“停止处理”和“继续处理”控制扫描与 AI 复核，已完成单元会保存。重新打开后可继续。
“清空工作区”确认后清空当前工作区全部内容；不要将工作区设为原照片目录或程序目录。
“不再自动检查更新”记忆勾选状态，手动检查更新仍可用。

完成 AI 选片并导出后，关闭或切换工作区会整理存储：清理可重建预览，归档项目状态，保留联系表与 AI 提交材料。再次选中工作区自动恢复，查看照片时按需重建预览，不重复调用 AI。
LR 导出结果保留在工作区 exports 文件夹内，不压缩；旧工作区可能位于根目录。

所有原照片保持原位置，不复制精选、不移动或删除原片、不生成 XMP。
全局 API 配置位于 settings；密钥保存在 Windows 凭据管理器，更换电脑需重新输入。
工作区保存在 workspaces，或使用自己的独立目录。窗口按屏幕居中，小屏可滚动。
