AI选片助手 v0.4.10 快速开始

1. 解压整个文件夹后启动 AI选片助手.exe。
2. 选择照片目录、工作区、精选导出目录，扫描生成联系表。
3. 可编辑分组、人脸细节，再保存并重新生成联系表。
4. 如需星级，把“文件名,星级”结果粘贴回软件。
5. 点击“导出 Lightroom 结果”，所有照片仍在原目录。
6. 点“LR 插件”打开插件目录，按其中“安装与使用.txt”安装一次。
7. 在 Lightroom Classic 插件中选择工作区 lightroom_results.json，检查匹配数量并应用。

本版本不再生成 XMP，也不删除旧 XMP。LR 插件直接修改 Catalog 的星级/弃置状态。
若希望照片目录不出现 XMP，请关闭 LR 的“自动将更改写入 XMP”。
原照片需已导入当前 LR 目录，且路径一致；未匹配项在导入报告中列出。
所有设置保存在 EXE 旁 settings.json，升级可复制保留。
