AI选片助手 v0.5.1 快速开始

1. 解压完整文件夹后启动 AI选片助手.exe，选择照片目录和工作区。
2. 扫描，修改分组和人脸细节。
3. 点“AI 选片与人工复核”，设置偏好，点“新建全量初选”。
4. 网页：选批次，复制提示词、打开本批图片目录，交给模型后粘贴 JSON 回答。
   API：选择千问、智谱、GPT 或 DeepSeek 预设，填对应平台密钥并测试保存，再开始未完成批次。
   其他接口选择“自定义”；修改地址/模型可展开高级设置。
5. “人工复核”中查看理由和原图，设置最终星级/旗标，逐张确认保存。
6. 导出已确认结果；未确认或已过时的结果不会导出。
7. 安装随包 lightroom/PhotoCullAssistant.lrplugin；在 LR 插件导入工作区 lightroom_results.json。
8. 可从 LR “查看上次导入报告”复制 JSON，再在软件“导入 LR 回执”。

所有原照片保留原目录，不复制精选，不移动/删除，不生成 XMP。
LR 自身若启用“自动将更改写入 XMP”，仍可能生成 XMP。
只填星级不会改旗标；选择“无标记”才清除旗标。
重启后扫描同一目录和工作区，即可恢复 AI 任务及人工结果。
接口密钥保存在 Windows 凭据管理器；更换电脑需重新输入。
