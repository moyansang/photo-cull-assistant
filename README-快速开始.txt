AI 选片助手 v0.4.5 — Windows 64 位便携版

1. 完整解压 ZIP，保留 AI选片助手.exe 和 _internal 文件夹在一起。
2. 双击 AI选片助手.exe，无需安装 Python。
3. 选择照片文件夹和工作区，点击“扫描并生成联系表”。
4. 需要时编辑选片组，再重新生成联系表。
5. 将工作区 contact_sheets/main 中的联系表上传给 ChatGPT 选片。
6. 将“文件名,星级”格式的评级粘贴回程序，应用选片结果。
7. 在 Lightroom Classic 中执行“元数据 → 从文件读取元数据”。

自动技术粗筛只对可靠检测到的脸部判断明显虚焦/抖动。
弃置结果请查看 contact_sheets/rejected_review 并人工复核。
程序不删除原片；评级和弃置信息写入 XMP。操作重要照片前建议备份已有 XMP。
RAW 预览所需 rawpy/LibRaw 和人物检测数据已随程序打包。
当前不直接调用 ChatGPT API，仍需手动上传联系表并粘贴评级。

目录设置会在关闭程序时保存到 EXE 旁的 settings.json，下次启动自动恢复。
首次默认工作区和精选导出目录均为 EXE 所在文件夹本身。
更新版本时，可将旧版 settings.json 复制到新版 EXE 旁以保留设置。

新版分组：Standard 使用 0.8/2.5 秒窗口并比较人物外观，短间隔也检查变化。
旧工作区保留原分组；要启用新版算法，扫描后点击“重新自动分组”（覆盖人工分组）。
联系表右侧显示可靠人脸的局部放大；未检测到或多人主体不明确时不显示。
更新时将旧版 settings.json 复制到新版 EXE 旁，即可保留目录设置。

v0.4.5：人脸小窗改用离线 YuNet 和五点关键点裁切，大小保持不变。
更新后复制原 settings.json，打开软件扫描，再重新生成联系表即可看到新版人脸框。
只更新小窗无需重新自动分组，已有人工分组会保留。
未达到置信度/关键点门槛的照片不显示小窗；模型已随 EXE 打包，无需联网。
YuNet 模型来源与许可见 _internal/ai_cull_assistant/data。

人脸细节设置：扫描后点击此按钮，可调裁切范围、上下偏移和比例。
左侧查看绿色裁切边界，右侧查看实际小窗。支持上一张/下一张和恢复默认。
点击保存并重新生成联系表后整批生效，不改变分组和评级。
参数自动保存在 settings.json，下次启动恢复；取消不会修改已保存设置。

从 v0.4.5 起：首次默认工作区和精选导出目录均为 EXE 所在文件夹本身。已保存的自定义目录不变。

人脸细节设置新增“检测置信度”：范围 0.70～0.95，默认 0.80。越低越容易检出，也可能错检；调整后看预览，保存使整批生效。
修改置信度会刷新检测；只调裁切仍复用结果。分组和评级不变。
