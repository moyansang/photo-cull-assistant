AI选片助手 v1.5.4 快速开始（程序版本 1.5.4）

1. 完整解压，运行 AI选片助手.exe；保留 _internal 和 lightroom 文件夹。
2. 选择照片目录与独立工作区，点击“扫描图片”：本地人脸检测、虚焦初筛与分组，不调用 API。
3. 编辑分组、调整人脸框；只重新扫描修改过的图片。
4. 可选“AI 复核”，然后“生成联系表”。未配置 API 可以跳过复核。
5. “AI 选片与导出”选择 API 或网页提交；网页可合并批次、复制一份提示词并上传图片。
6. 查看 AI 评分/理由，导出到 LR。用随包 lightroom/PhotoCullAssistant.lrplugin 导入结果并检查原图。

照片增加：提示数量，点击扫描只处理新增或 RAW/JPG 配对变化的照片。
照片减少：保留工作区，移除缺图记录，重新生成联系表；不需要全量重扫。
整个照片目录无法访问时先检查磁盘。原片内容修改仍需重扫。
没有新增文件时点击扫描仍会进行完整扫描。

停止/继续会保存完成部分。关闭后可恢复分析；按条件归档状态与清理缓存，联系表、提交材料、导出保留。清空工作区会清除该工作区数据，操作前有确认。
清晰度待确认照片不进入正式 AI 选片，可导出到 Lightroom 智能收藏夹检查。
身体清晰度检查是默认关闭的实验选项。当前正式版使用 CPU，不支持 GPU 加速。

原照片不移动、不删除、不复制精选；弃置仅为结果标记。API Key 保存在当前 Windows 用户凭据管理器，换电脑需重填。插件本身不写 XMP，LR 自动写 XMP 由 LR 自身设置控制。

工作区迁移：复制整个工作区。若原片从 E 盘变为 G 盘等路径变化，点击“重新定位原照片”，选择同一批照片的新位置。按相对路径、大小、修改时间核对后保留分析和暂停进度；文件不一致时拒绝关联，中断任务有缺图时需先补齐。在新电脑明确选择复制来的工作区；若放在程序默认 workspaces 目录内，也可先选择照片目录，程序会查找匹配的工作区。发现多个匹配副本时需明确选择，避免误开。不要只复制联系表或缓存。
AI 任务恢复：压缩、清理图片缓存和迁移工作区不代表重新选片。已完成的任务、评分和原始回答应继续保留；缺失的提交图片在需要该批次时恢复。
合照人脸：单人默认检查主体；多人时选择需要参与检查的合影成员，背景路人或海报脸不要选入。每个成员分别调整裁切；任一成员明确模糊则弃置，有成员无法确定则保留清晰度待确认。
同版本更新：程序额外记录构建号。相同版本号的较新构建可作为修复更新；旧包没有构建号按 0 处理。尚不支持此机制的旧程序需手动安装一次新包。

预览与细节缓存：人脸窗口按内存预算复用图片与检测结果，并预加载附近照片。新扫描尽量复用已解码原图准备待复核细节；暂停时保留，整轮 AI 复核完成后清理临时细节缓存，AI 结果和审计记录保留。旧工作区首次复核可能仍需解码。
