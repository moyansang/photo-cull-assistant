# AI 选片助手 v0.4.6

## v0.4.6 人脸检测置信度

“人脸细节设置”新增检测置信度滑块，范围 0.70～0.95、默认 0.80。值越低越容易显示人脸，也可能增加误检；几何关键点检查保持不变。保存后整批联系表生效，参数写入 settings.json，旧设置缺失此项时使用 0.80。
仅改裁切参数复用检测；改变置信度会更新检测结果，缓存按置信度区分。不会改动已有分组和评级，分组内部的人物比较仍使用原检测门槛。

## v0.4.4 中文分组档位

软件中的分组灵敏度显示为“严格 / 标准 / 宽松”，分别对应原 Strict / Standard / Loose；算法参数不变，人脸检测门槛也不变。

## v0.4.3 默认目录

首次启动时，工作区和精选导出目录都直接使用 AI选片助手.exe 所在文件夹。已保存的自定义目录继续恢复。

## v0.4.2 可配置人脸裁切

点击主界面“人脸细节设置”：范围 0.6～2.0（默认 1.0）、上下偏移 -0.5～0.5（默认 0，负值向上）、比例 124:150 / 1:1 / 3:4。范围和偏移以当前头部裁切框为基准，偏移单位为其高度。
左侧实时显示裁切边界，右侧显示固定 124×150 小窗；比例变化时等比缩放留白。可切换前后照片、恢复默认、取消不保存。
点击“保存并重新生成联系表”应用全局参数，不重新检测、不改变分组或 XMP。设置保存在 settings.json 的 face_crop 字段，兼容原目录设置。未扫描时也可以先保存参数。

## v0.4.1 YuNet 人脸细节

人脸细节和分组主体定位改用 OpenCV YuNet（2023mar，适配 OpenCV 4.x）。模型随程序离线分发，使用时不联网、不上传照片；来源和 MIT 许可在 `_internal/ai_cull_assistant/data/`。
显示门槛为置信度至少 0.9，并检查五点关键点的几何关系、框尺寸和边界；多人人脸大小接近时不选择主体。没有可靠结果时不回退到旧 Haar 放大框。
裁切结合双眼位置与脸框，向头发区域留出空间，保持原来的 124×150 小窗尺寸。分组参数不变；技术废片自动弃置仍使用原来的保守筛选逻辑。

测试：从用户上传的联系表提取 16 张缩略图，13 张通过检测，人工目视检查检测框均位于脸部，另外 3 张不显示。此结果仅适用于该低分辨率样本，不能代表原片或其他批次的成功率。原片需重新生成联系表验证。

## v0.4.0 分组和人脸细节

- Strict / Standard / Loose 时间窗口为 0.5/1.5、0.8/2.5、1.2/4 秒。短间隔也会检查视觉变化。
- 可靠单人脸用于定位上半身区域，优先比较主体外观、脸部位置和大小，整图辅助；无可靠检测时比较整图和中央区域。不是骨骼姿态识别。
- 同时参考组内第一张，减少渐变动作连续串成大组；不设置按张数硬拆组。
- 联系表保留完整照片，右侧独立显示可靠检测的人脸细节，标签采用“文件名 · #序号”。多人主体不明确时不显示放大框。
- 预览升级到最长边 1600px，使用 previews/v04 缓存。人脸放大不生成原图不存在的细节。
- 已保存分组继续保留；旧工作区要使用新版算法，扫描后点击“重新自动分组”，此操作会覆盖人工分组。

分组阈值仍需用实际漫展连拍验证。侧脸、遮挡和小人脸可能不被检测到。

## v0.3.1 目录记忆

关闭窗口时自动保存照片文件夹、工作区和精选导出目录，下次启动恢复，包括手动输入的路径。
首次启动默认使用 EXE 旁的 `工作区/` 和 `精选/`，不受启动时的当前目录影响。
设置保存在 EXE 旁的 `settings.json`；更新到新文件夹时复制此文件即可保留设置。
程序文件夹需要可写权限。设置文件不存在或损坏时使用默认目录。

面向 **漫展 / Coser / 人像 / 舞台** 的 Windows 本地批量选片工具。

当前工作流：

1. 扫描照片目录
2. 合并同名 `RAW + JPG` 为一张逻辑照片
3. 提取 RAW/JPG 预览
4. 按时间 + dHash 自动生成“选片组”
5. 可人工拆组 / 合组，并保存到 `groups.json`
6. **仅对可靠检测到的人物主体做“明显虚焦 / 严重抖动”保守粗筛**
7. 高置信度技术废片写为 Lightroom **弃置旗标**：`xmpDM:pick = -1`、`xmpDM:good = false`
8. 生成适合上传给 ChatGPT 的主联系表 + 弃置复核表
9. ChatGPT 负责表情、动作、构图、重复度等真正的审美选片
10. 把 ChatGPT 评级粘贴回来，写入 Lightroom XMP 星级

> v0.3 的自动粗筛 **不处理重复片、不判断表情、不挑同组最佳、不删除原片**。

## v0.3 新增

### 1. 人物主体技术粗筛

主界面默认开启：

```text
人物主体明显虚焦/严重抖动 → Lightroom 弃置（保守模式）
```

逻辑：

```text
预览图
  ↓
检测可靠人物脸部
  ↓
检测不到脸 / 不够确定
  → 不处理

找到主要人物脸部
  ↓
只分析人物脸部区域清晰度
  ↓
只有“非常明显的虚焦 / 严重抖动”
  → Lightroom 弃置旗标（xmpDM:pick=-1）
其他情况
  → 不处理
```

主目标是 **宁可漏掉一部分废片，也尽量不误杀正常照片**。

每次扫描还会保存：

```text
工作区/
  screening_results.json
```

里面记录每张照片是否检测到可靠人物主体、是否自动弃置以及清晰度分数，方便排查误判。

### 2. 联系表针对 ChatGPT 优化

默认：

- 4 列
- 默认每页最多 16 张（可调 8～60）；小组选片过多时会为了控制页面高度自动提前分页
- 页面宽度约 2024 px，且会把页面高度控制在约 2800 px 内，适合聊天上传
- 缩略图保持原始比例，不裁切人物
- 同组选片尽量不跨页
- 每组顶部显示 `Gxxx · N photos`
- 大组跨页时显示 `part 1/2`、`part 2/2`
- 照片只保留醒目的文件名、组号、组内序号
- 不显示拍摄时间等干扰信息

输出结构：

```text
工作区/
  contact_sheets/
    main/
      sheet_001_G001-G005_P1111597-P1111630.jpg
      ...
    rejected_review/
      sheet_001_G003-G010_P1111602-P1111701.jpg
      ...
```

`main/`：正常上传给 ChatGPT 选片。

`rejected_review/`：只放自动弃置的技术废片，供人工快速复核。

自动弃置的照片默认不进入 `main/`，减少上传量。

### 3. Windows 便携 EXE 构建

推荐 **PyInstaller one-folder**，而不是 one-file。

Windows 上最省事：


会生成：

把便携 ZIP 发到另一台 Windows 电脑，完整解压后双击 `AI选片助手.exe` 即可；目标电脑无需安装 Python。

## 普通 Windows 用户怎么用

如果拿到已经打好的便携包：

1. 完整解压 ZIP
2. 双击 `AI选片助手.exe`
3. 选择照片文件夹
4. 默认保持技术粗筛开启
5. 点击 **扫描并生成联系表**
6. 需要时进入 **编辑选片组**，人工拆组 / 合组
7. 点击 **重新生成联系表**
8. 把 `contact_sheets/main/` 上传给 ChatGPT
9. 把 ChatGPT 返回的评级粘贴回程序
10. 点击 **应用选片结果**
11. Lightroom Classic：`元数据 → 从文件读取元数据`

## 联系表上传给 ChatGPT 的推荐提示词

```text
请按组选片。
同组主要比较：眼神、表情、动作完成度、手脚姿态、头发/服装状态、构图和重复度。
优先每组选 1 张最佳，必要时再留 1 张备选。
只按以下格式输出：
文件名,星级
```

例如：

```text
P1111599,5
P1111598,4
P1111604,5
P1111608,5
P1111607,4
```

也支持：

```text
S: P1111599 P1111604 P1111608
A: P1111598 P1111607
B: P1111597
```

映射：

- S → 5 星
- A → 4 星
- B → 3 星
- C / REJECT → 1 星

自动技术弃置使用：

- `xmpDM:pick = -1` + `xmpDM:good = false`（Lightroom Classic 13.2+ 弃置旗标）
- 不会占用或覆盖 0～5 星评级

## 自动分组

### standard（推荐）

- 相邻照片 ≤ 1.2 秒：倾向同组
- 1.2～4 秒：结合 dHash 相似度判断
- > 4 秒：默认新组

这里的“组”定义为：

> 应该放在一起互相比较，最后挑最好照片的一组选片候选。

## 当前限制

- 人物检测第一版使用 OpenCV 正脸检测，侧脸、背脸、遮挡严重或人物太小时会选择“不处理”，而不是冒险弃置。
- 技术粗筛阈值刻意设置得很保守，因此会漏掉一些轻微虚焦片。
- 还没有闭眼检测。
- 还没有人体姿态识别。
- 不自动处理重复片；重复照片仍由 ChatGPT 按组选片。
- 没有直接调用 ChatGPT API，目前仍是“上传联系表 + 粘贴评级结果”的方式。
- PyInstaller 不能跨平台生成 Windows EXE；Windows EXE 必须在 Windows 本机 / VM / GitHub Actions Windows runner 构建。


### v0.4.6 人脸细节与设置记忆
- 自动选脸以置信度为主，结合画面位置；不再优先选面积最大的背景脸。
- 人脸细节设置中点击蓝色候选框选脸，漏检时拖框圈住脸部；支持隐藏本张小窗、恢复自动选脸。
- 裁切范围、上下偏移、比例按原照片绝对路径独立保存。原照片移动后需要重新设置。
- 检测置信度全局生效，手动指定的人脸不受置信度影响。点击“保存并重新生成联系表”保存逐张修改；取消放弃本次修改。
- 分组灵敏度、每页照片数、列数、技术筛选开关和三个目录自动记忆。设置存于 EXE 旁 settings.json，升级可复制该文件。
